# Login-Register-Notebook-system
Login/ Register notebook system made in python. IGNORE userpass.txt and User_Data, fake example data used for testing. 
Features
- Register with name, username, email + strong password checks
- Email validation with regex (checks for @ and .com style)
- Password must be 8+ chars with uppercase, lowercase, number + symbol
- Checks for taken usernames/emails
- Login with exact username/password match
- Creates a personal folder + `notebook.txt` for each user
- Write and save notes to your own notebook
- Import os + re for email validation and file handling
